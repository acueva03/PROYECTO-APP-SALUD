### Entorno de Desarrollo:
Para facilitar la programación sin necesidad de conocer sistemas complejos, utilizaremos Python
como lenguaje principal. Recomendamos el uso del editor Visual Studio Code junto con Flask, un
entorno de trabajo para Python que hace muy sencillo crear páginas web interactivas.

### Interfaz Visual:
La interfaz visual que utilizará el usuario (Frontend) seguirá utilizando HTML5, CSS3 y JavaScript
para garantizar que funcione en cualquier navegador web, mientras que el motor interno (Backend)
gestionará toda la lógica, cuentas y datos desde Python.
